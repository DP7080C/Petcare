# 🐾 PetCare

PetCare es un prototipo web académico orientado a ofrecer información
confiable sobre el cuidado de mascotas y una comunidad para compartir
experiencias.

## ✨ Características

-   🟢 Biblioteca de 50 artículos de información verificada.
-   🤖 Tofi, asistente que consulta exclusivamente la biblioteca
    verificada de PetCare.
-   🐶🐱 Mascota visual de Tofi integrada en la interfaz.
-   🔎 Búsqueda de información por temas.
-   👥 Comunidad para compartir experiencias.
-   🛡️ Moderación automática y segunda revisión para consultas que lo
    requieran.
-   👤 Prototipo de cuentas, perfiles y registro de mascotas.
-   📱 Diseño adaptable a diferentes tamaños de pantalla.

## 📚 Fuente de referencia

La biblioteca utiliza como referencia el **Manual Veterinario MSD** y
sus contenidos para propietarios de mascotas.

Las experiencias publicadas por la comunidad se mantienen separadas de
la biblioteca verificada y no se utilizan como fuente para las
respuestas de Tofi.

## 🚀 Publicación en GitHub Pages

1.  Subir los tres archivos a la raíz del repositorio.
2.  Entrar en **Settings → Pages**.
3.  Seleccionar **Deploy from a branch**.
4.  Elegir `main` y `/ (root)`.
5.  Guardar y esperar la publicación.
6.  Si aparece una versión anterior, usar `Ctrl + F5`.

## ⚠️ Nota sobre el prototipo

Esta versión es un prototipo front-end. Las cuentas, comunidad y
moderación funcionan como demostración local y requieren un backend y
una base de datos para producción.
