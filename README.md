# PetCare — Prototipo funcional

## Qué incluye
- Inicio y navegación SPA
- 20 artículos de demostración
- Categorías
- Tofi con regla de oro: solo usa los 20 artículos
- Respuesta de Tofi cuando no existe información suficiente
- Artículos con fuentes, fecha y palabras clave
- Comunidad con usuarios, mascotas, comentarios y respuestas simuladas
- Perfil y mascotas
- Login visual/demo
- Responsive

## Publicación
Este proyecto es estático: basta con subir `index.html` a un repositorio de GitHub y activar GitHub Pages desde Settings > Pages > Deploy from a branch > main > /(root).

## Importante
La autenticación, base de datos, persistencia de comentarios y Tofi con IA/RAG real todavía son simulados. La estructura está preparada para una segunda fase.
